# resource_mail Requirements

## Module Overview
- **Name**: Resource Mail
- **Category**: Hidden
- **Description**: Integrate features developed in Mail in use case involving resources instead of users
- **Author**: Odoo S.A.
- **License**: LGPL-3
- **Version**: 1.0

## Technical Details

### Dependencies
- `resource`
- `mail`
- Auto-installs: True

### Assets
- `web.assets_backend`: All static src files
- `web.assets_unit_tests`: Unit tests

### Purpose
Bridge module that integrates Mail features for resources (instead of just users), enabling mail notifications for resource-based scheduling.
