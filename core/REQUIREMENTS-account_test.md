### Notes

- Installable: True
- Category: Accounting/Accounting
- Description: With this module you can manually check consistencies and inconsistencies of accounting module from menu Reporting/Accounting/Accounting Tests. You can write a query in order to create Consistency Test and you will get the result of the test in PDF format which can be accessed by Menu Reporting -> Accounting Tests, then select the test and print the report from Print button in header area.
