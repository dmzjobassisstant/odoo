## Description
Chart of Account for Venezuela.

Venezuela doesn't have any chart of account by law, but the default proposed in Odoo should comply with some Accepted best practices in Venezuela, this plan comply with this practices.

This module has been tested as base for more of 1000 companies, because it is based in a mixtures of most common software in the Venezuelan market what will allow for sure to accountants feel them first steps with Odoo more comfortable.

This module doesn't pretend be the total localization for Venezuela, but it will help you to start really quickly with Odoo in this country.

This module gives you:
- Basic taxes for Venezuela
- Have basic data to run tests with community localization
- Start a company from 0 if your needs are basic from an accounting PoV

We recommend use of account_anglo_saxon if you want valued your stocks as Venezuela does with out invoices.
